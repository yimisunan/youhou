## 🛠️ 脚本详情

### 1. APP体验防重助手（纳入与排除检测·可折叠贴边版） `v1.2.0`

适合在安卓浏览器逛应用推荐、网盘分享、资源站或下载页时，快速标记并排查自己已经体验过的 APP，避免重复下载或踩坑。

- **按需智能唤醒（零日常浏览污染）**：
  - 仅当当前网页链接、下载属性、URL 或可见正文中出现 `.apk` 或 `.exe` 时才会显示悬浮检测界面；普通新闻、视频、搜索等日常网页完全无打扰。
  - 内置动态 DOM 监听与 SPA 路由监听，异步加载网盘/下载链接后自动唤醒；也可随时通过油猴菜单手动强制开启/关闭。
- **安卓底部弹窗 & 贴边折叠胶囊**：
  - 采用 Shadow DOM 隔离，适配手机端底部抽屉（Bottom Sheet）与底部安全区 `safe-area-inset`，按钮触控面积更大、单手操作更顺手。
  - 支持触屏上下拖拽与左右边缘自动吸附记忆；支持「点击网页空白处自动收起」。
- **本页安装包一键提取纳入**：
  - 自动识别页面中的 `.apk` / `.exe` 包名与下载按钮标题，在面板顶部生成快捷标签，**点一下即可直接纳入并重检**，告别手机端反复长按选字的麻烦。
  - 同时保留「填入选中字」与批量文本输入（换行/逗号/分号分隔去重）。
- **更舒适的自动静默检测与定位**：
  - 唤醒时默认自动静默检测（仅在胶囊上以**红/绿颜色**直观提示，不弹多余提示打扰阅读）；同时检索页面可见文本与下载链接属性中的包名。
  - 命中时支持网页正文高亮、循环滚动定位（当前定位词高亮突出）及一键清除当前页高亮。
  - 支持「区分大小写」开关、关键词搜索、剪贴板导出、`.txt` 文件导出备份与 `.txt`/`.json` 文件导入。

### 2. 安卓网页离线保存器（HTML / PNG） `v1.1.0`

用于在安卓端快速归档当前正在浏览的网页，提供「单文件离线 HTML」「PNG 长截图」与「PNG 当前屏幕截图」三种导出方式。

- **Shadow DOM 隔离与可拖拽贴边球**：
  - 界面完全运行在 Shadow DOM 中，不受原网页 CSS 样式污染影响。
  - 悬浮按钮支持拖拽并自动贴合屏幕左/右边缘、记忆位置，点击弹出安卓风格底部操作面板（显示当前网页标题、域名与尺寸及实时导出进度条）。
- **离线 HTML 高保真引擎**：
  - **跨域资源增强**：通过 `GM_xmlhttpRequest`（并自动回退 `fetch`）并发抓取跨域图片、SVG `<image>` 与外链 CSS，突破普通网页 CORS 限制。
  - **懒加载与状态同步**：自动提取 `currentSrc`、`data-src`、`data-original` 等懒加载图片并移除 `srcset`/`loading="lazy"`；完整保留 `input`/`textarea`/`select`/`details`、`<canvas>` 像素与滚动位置；自动清理快照内限制本地渲染的 CSP meta 标签。
  - **轻量模式 vs 样式锁定模式**：默认采用「高保真 CSSOM + 样式表合并」模式（文件体积更小、打开更快）；针对极少数特殊网页提供「锁定全元素计算样式」开关。
- **更稳健的 PNG 导出**：
  - **PNG 长截图**：自动根据移动端画布像素/边长安全上限（约 2000 万像素）动态调整缩放比例，大幅降低长页面崩溃失败率。
  - **PNG（当前屏幕）**：针对超长页面提供极速当前可视区域截图，秒级生成不卡顿。
  - 兼容 `html2canvas` 1.4.1（同时检测沙盒作用域与 `window` 挂载）及 `GM_download` / `<a download>` 下载回退。

## 📱 安卓端推荐使用环境

以下安卓端浏览器与脚本管理器均可配合本仓库脚本使用：

- **Kiwi Browser / Lemur Browser（狐猴浏览器） / Edge Canary**：安装 **Tampermonkey（篡改猴）** 或 **Violentmonkey（暴力猴）** 扩展。
- **Firefox for Android**：安装 **Tampermonkey** 或 **Violentmonkey** 附加组件。
- **Via 浏览器 / X 浏览器**等轻量浏览器：支持通过内置脚本管理导入（其中仅依赖原生 JS 的「APP体验防重助手」可直接运行；「安卓网页离线保存器」建议在支持 `@require` 与 `GM_xmlhttpRequest` 的完整油猴环境中使用以获得最佳跨域离线效果）。
